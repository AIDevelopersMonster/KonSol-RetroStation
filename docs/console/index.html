03 / PROGRAM FPGA SRAM

Подключите Tang Nano 9K

Chrome или Edge → JTAG Debugger (FT2232 A, 0403:6010). В Windows интерфейс A должен использовать WinUSB, интерфейс B остаётся COM-портом для UART. Не отключайте USB при записи.

Устройство ещё не выбрано.

ВЫПОЛНЯЕМАЯ КОМАНДАopenFPGALoader -c ft2232 -b tangnano9k game.fsНет опции Flash, стирания или постоянной записи.
Ожидается проверенная прошивка и разрешение на JTAG.

04 / LIVE GAMEPAD

Управление игрой через UART

Выберите FT2232 USB Serial Port (интерфейс B), 115200 8N1. После подключения нажмите на поле управления — события клавиатуры пойдут в FPGA, а не в эмулятор.

←↑↓→PRНажмите здесь и используйте клавиатуру

Для каждой игры назначение клавиш своё.

В PONG кнопка «Старт» не требуется. Для BREAKOUT, K-BLOCKS, LIGHT CYCLES, SPACE PATROL и MAZE CHASE клавиша P запускает игру. Потеря фокуса отправляет x, освобождая зажатые клавиши.

01. Проверить файл

SHA-256 должен совпадать с опубликованным значением для выбранной игры и платы.

02. Загрузить SRAM

JTAG A выполняет конфигурирование FPGA. При снятии питания прошивка теряется.

03. Играть на HDMI

FT2232 B принимает команды клавиатуры по UART. Вывод изображения — на физический HDMI-монитор.
